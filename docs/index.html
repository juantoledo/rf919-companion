    Key capture

    Shows what the radio reports when you press one of its own buttons. The RF919 doesn't send key codes, only what changed (a frequency, channel mode, a setting…), so each press shows a guess at the button, what changed, and the raw messages. Nothing is sent to the radio.

    Off
      Test one memory

      Runs the store sequence with fixed pauses and marks each step in the log, to find out which keys and replies the radio really uses (memory.md §8).

      Test band wipe holds SCAN on the band above (deleting all its memories), listens 5 s, then recalls CH 1.

      Developer: send a frame

      Type a command byte and data bytes in hex.

      Sent on FF13, like every other command; the checksum is added. Replies show in the log. An unknown command could change a setting.
